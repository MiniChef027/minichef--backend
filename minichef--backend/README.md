# 🍳 MiniChef

> Um projeto pensado para transformar a experiência na cozinha de quem a vivencia no dia a dia.

---

### 📖 Sobre o Projeto

O **MiniChef** é uma aplicação focada em gestão e organização culinária, planejamento de refeições, controle de despensa e receitas. Nascido da vontade de simplificar e tornar a cozinha mais acessível, o projeto foi desenvolvido para **todos os perfis de pessoas**: desde *chefs* profissionais buscando otimizar sua rotina até iniciantes que estão aprendendo a cozinhar do zero.

Seja para ajudar quem já domina as panelas a gerenciar melhor seus ingredientes e pratos, ou para introduzir de forma leve e intuitiva aqueles que querem começar a cozinhar por conta própria, o **MiniChef é para todos**.
